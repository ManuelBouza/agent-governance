# D004 — Mandatory F0-F6 pre-implementation lifecycle

Status: ACCEPTED
Authority: Human Owner
Origin: migrated from the original `script-uh` governance testbed.

## Decision
Every implementation scope must pass framing, viability, engineering strategy, Skill capability audit, atomic planning, readiness review, and persisted handoff before work becomes READY.

## Rationale
Planning tasks too early mixes strategic decisions with implementation detail and gives the implementation agent immature or ambiguous work.

## Consequences
Later phases may explicitly reopen earlier phases. Decisions are persisted continuously; F6 consolidates rather than becoming the first persistence point.
