# D012 — Public reusable distribution

Status: ACCEPTED
Authority: Human Owner

## Decision

`ManuelBouza/agent-governance` is intentionally maintained as a public repository and the product is intended for adoption by external users, projects, teams and compatible agent ecosystems.

Public visibility is part of the product strategy, not a temporary development state.

## Rationale

The governance framework is designed to be agent-product neutral and reusable beyond its original testbed. Public development enables independent inspection, portability testing, external feedback and broader adoption.

## Consequences

- Product documentation, examples, tests and releases must avoid private/project-specific information.
- The public repository remains the canonical development source.
- Consumer-specific mission/state records never belong in this source repository.
- Public contributions or third-party artifacts do not bypass governance, provenance, review or Skill supply-chain controls.
- A formal open-source license, contribution policy and release policy must be selected before claiming unrestricted redistribution rights or publishing a stable general-use release.
