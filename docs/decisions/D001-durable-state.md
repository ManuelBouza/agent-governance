# D001 — Durable project state

Status: ACCEPTED
Authority: Human Owner
Origin: migrated from the original `script-uh` governance testbed.

## Decision
Project state must be reconstructible from the repository by a stateless authorized agent. Chat history is never required for the next permitted action.

## Rationale
New Strategy or Implementation Agent sessions must preserve decisions and current progress without manual context transfer.

## Consequences
STATE is a compact derived checkpoint; authoritative mission/work/decision history remains in versioned repository records and EXCHANGE.
