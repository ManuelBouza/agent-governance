### AC-T021-2 — FAIL

The public `Profile` dataclass can be directly constructed with an unsupported identity, while `engine.main()` validates only that the object is a `Profile` instance and that `profile.grants_source_maintenance` is false.

In the submitted implementation:

```text
Profile(name="source-maintainer")
Profile(name="garbage")
```

are constructible. For every `Profile`, `grants_source_maintenance` currently returns `False`. Therefore either object passes the `isinstance(profile, Profile)` and `not grants_source_maintenance` checks in `engine.main()` and proceeds through the Consumer command path without passing through `resolve_profile()`.

This violates the first required property of AC-T021-2:

> Unsupported or ambiguous profile values are rejected.

The existing negative controls exercise `resolve_profile(<bad-value>)` but do not exercise the engine boundary with a directly constructed unsupported `Profile` instance. The routing boundary therefore has an uncovered bypass.

## Required T021 rework

- `Profile("source-maintainer")`;
