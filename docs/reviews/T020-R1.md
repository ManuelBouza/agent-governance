## Finding 1 — distribution payload boundary is too broad

`src/agent_governance/artifact.py` copies the complete `governance-skill/` source subtree into the built artifact. That includes `governance-skill/STATUS.md`.

`STATUS.md` is source-product lifecycle/status metadata and contains source-layout references such as `../docs`, `../maintainer-skill`, and `../governance-core`. It is not required for Consumer operation and becomes a broken source-tree reference inside the self-contained distribution artifact.

T020 requires a self-contained Consumer payload and explicitly excludes source-only policy/state/history from being used to obtain self-containment. The build boundary therefore must be an explicit intended Consumer payload rather than an indiscriminate copy of the entire source Skill subtree.

### Required rework

- Exclude source-product lifecycle/status metadata such as `governance-skill/STATUS.md` from the generated Consumer artifact.
- Make the intended Skill-source packaging boundary explicit rather than relying on broad subtree copying plus accidental inclusions.
- Add deterministic regression coverage proving `STATUS.md` is absent from the built artifact while the required Consumer Skill files/assets/scripts remain present.
- Do not edit committed Markdown as part of T020 implementation.

## Finding 2 — artifact-only operation evidence is incomplete

The artifact-isolation test correctly stages disposable source inputs, builds the artifact, deletes the staged source tree, proves runtime/Core/assets resolve below the artifact root, and executes `bootstrap`, `validate`, and `state` against an unrelated repository.

However, for the remaining Consumer v1 commands — `event`, `skill`, `ecosystem`, and `archive` — the test only verifies that their names appear in `--help`.

Parser exposure is not equivalent to execution evidence. T020 acceptance requires normal Consumer v1 deterministic operations used by the current release gate to work from the artifact-only environment.

### Required rework

While the staged source tree remains absent, add representative valid artifact-only execution coverage for:

- `event`;
- `skill`;
- `ecosystem`;
- `archive`.

The exact seven-command Consumer v1 surface and T018/T019 frozen behavior must remain unchanged.
