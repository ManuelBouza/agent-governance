## Probe results

### P1 — deterministic inventory

CONTROL passed. ADAPTIVE `GPT-5.6 Luna / Low` failed the exact physical-LOC oracle because it used a line-count method that excluded blank lines. The first-attempt failure is material under the frozen exactness rule and remains scored `0`.

A permitted fresh `Terra / Medium` diagnosis correctly identified the counting-semantic error and recovered the oracle values. The escalation does not replace the failed first-attempt score.

Interpretation: this is direct evidence that the frozen `Luna / Low` mapping was not reliable enough for this exact-evidence task as specified.

### P2 — dependency and symbol map

Both CONTROL and ADAPTIVE returned the same 18 expected characterized edges **plus one additional facade-to-package-`__init__` edge**. Both therefore fail the frozen exact-edge-set oracle while correctly reporting acyclicity and all six symbol owners.

The canonical characterization in `tests/test_repository_context_extraction.py` confirms the 18-edge oracle and excludes that package-bootstrap edge.

This is a formal failure for both arms, but it is **not evidence that `Terra / Medium` underperformed CONTROL**. The prepared probe asked for dynamic source-package loads as dependencies, while the frozen characterization excludes package-bootstrap `__init__` execution from the dependency edge set. Because both model tiers made the identical extra-edge interpretation, P2 has a shared task/oracle-semantics confound for causal model comparison.

A permitted `Sol / Medium` diagnosis reproduced the canonical 18-edge characterization and distinguished loader/bootstrap mechanics from characterized module dependencies. It does not replace the first-attempt scores.

### P3 — adversarial independent review

Both arms passed.

The requested ADAPTIVE profile was `GPT-5.6 Terra / High`; CONTROL inherited root-equivalent `Sol / Medium`. Both identified the seeded high-severity same-process `sys.modules` contamination mechanism, supplied the expected proof direction, and proposed source-specific namespace/isolation as the fix direction. No invented material finding was recorded.

This supports the quality hypothesis that the requested lower model tier with higher task-specific reasoning can handle this bounded adversarial review. Because effective child profile identity was not observable, it does not verify that the host actually resolved the child to the requested profile.
