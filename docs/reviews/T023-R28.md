## S3 — Preserve absolute qualification thresholds

Each candidate independently must satisfy:

- activation precision `>= 0.95`;
- activation recall `>= 0.95`;
- activation F1 `>= 0.95`;
- false activation rate `<= 0.05`;
- wrong-specialist rate `<= 0.05`;
- overactivation rate `<= 0.05`;

- zero critical cross-profile violations;
- zero critical ambiguous-context permission broadening;
- deterministic/profile/source/distribution/single-install non-regression gates.

No threshold is weakened in response to v12-v14 failures.

## S4 — Qualifying-control materiality

If B2 qualifies, the established materiality rule remains unchanged:

```text
F1 >= B2 F1 + 0.03
median observed context bytes <= 0.85 * B2
false activation rate <= B2
wrong-specialist rate <= B2 + 0.01
overactivation rate <= B2 + 0.01
```

A split candidate must independently qualify before materiality is evaluated.

If neither split is material, B2 is the selected topology result.

If one split is material, select it.

If both are material, use the preserved tie-break: higher F1, then lower false activation, then lower context, then fewer entrypoints, then F2 for an exact remaining tie.

## S5 — Non-qualifying-control admissibility dominance

If B2 reaches scientifically valid non-qualification or `FUTILE_QUALIFICATION`, B2 is not release-eligible but does not block F2/G3.

A split candidate is selection-eligible only when it independently qualifies and satisfies all of:

```text
median observed context bytes <= 0.85 * B2
false activation rate <= B2
wrong-specialist rate <= B2 + 0.01
overactivation rate <= B2 + 0.01
zero critical cross-profile violations
zero critical ambiguous permission broadening
all deterministic/non-regression gates PASS
```

In this regime, qualifying-vs-nonqualifying status replaces the prior `F1 >= B2 + 0.03` uplift requirement. The absolute F1 threshold remains `>= 0.95`.

If neither split satisfies admissibility dominance, no topology is selected.

If exactly one does, select it.

If both do, use the same preserved tie-break.
