# Maintainer Executor Route

Use only when a persisted Task Contract/published candidate authorizes the product-agnostic Executor. `AGENTS.md`, the exact Task Contract, and represented Git state control.

## Minimum load

Load only:

1. `AGENTS.md`;
2. the assigned `docs/tasks/TNNN-*.md`;
3. the exact candidate branch/implementation anchor and current protected-base relationship;
4. controlling references named by the Task Contract;
5. frozen Orchestrator-owned conformance assets when selected;
6. `docs/EXECUTOR-HANDOFFS.md`;
7. the smallest applicable source toolchain/test/eval references.

Do not load a parallel strategy layer or infer missing semantics from chat history.

## Stage 6 envelope

The Executor may execute the candidate, diagnose failures, perform technical Code Review & Verify, make bounded non-Markdown repairs inside approved semantics/Design, strengthen supplementary technical coverage inside the authorized envelope, and persist the required non-Markdown handoff/evidence.

The Executor must stop for Orchestrator re-entry when it encounters a material requirement, Design, Plan/Trace, acceptance, semantic-oracle, authority, or topology defect.

D076 applies to every file-based executable artifact created and used during Stage 6. Small mechanical aids are allowed; a substantial missing controller/harness/script/fixture/oracle/grader requires Stage 5 re-entry. Temporary/untracked/deleted status never changes ownership.

## Mechanics and return

D054 gives the Executor command/API/SDK/shell/Git/tool mechanics. Use repository runbooks or authoritative installed/version-specific/vendor documentation and verify postconditions.

For delegated session preparation/return, compose `executor-launch-handoff`; use its workspace-isolation internal reference when writable collision/continuation safety is material. Repository branch/base/integration rules still come from Agent Governance policy / `repository-change-control`.

A terminal Stage 6 result must be reconstructable from canonical Git. Persist the handoff required by `docs/EXECUTOR-HANDOFFS.md`, commit authorized state, push the topic branch, verify the remote HEAD, and return only the contracted status/pointer fields. Green execution is evidence, not semantic acceptance.
