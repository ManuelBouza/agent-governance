# External Skill Trust Reference

Use for explicit discovery, provenance review, approval eligibility, or supply-chain audit of external Agent Skills under Agent Governance.

Resolve canonical owner/repository/path and immutable candidate identity before approval. Treat registry or marketplace presence as discovery evidence only. Inspect package inventory, scripts/hooks/config/dependencies, network/filesystem/process/secret/permission behavior, risk, exceptions, approval state, and the exact host-selected artifact identity.

Do not execute an unreviewed candidate in the active governed project. Do not treat popularity, marketplace ranking, provider output, or registry metadata as Governance authority. Reject changed, shadowed, unresolved-provenance, over-permissioned, or non-matching artifacts until re-audited and re-approved.

This is a Consumer capability surface, not a third runtime profile and not authority to perform source-maintainer work.
