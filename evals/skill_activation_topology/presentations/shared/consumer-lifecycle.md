# Consumer Lifecycle Reference

Use only for Agent Governance work in an adopting Consumer repository.

Activate this capability for explicit requests to bootstrap or validate Agent Governance, inspect or refresh Governance state, record authorized lifecycle events, work with mission/workplan/task sequencing and handoffs, prepare archive operations, inspect coexistence, or operate accepted Consumer Governance lifecycle behavior.

The Consumer profile owns `.agent-governance/` and `.agent-coordination/` only through accepted runtime semantics. Read-only inspection is the default; mutation requires an already-authorized Governance operation. Do not infer strategy, requirements, Design, acceptance, approvals, or source-maintainer authority.

Do not use this capability for generic coding, testing, refactoring, releases, generic SDD/tooling, generic Skill installation, or maintenance of the canonical Agent Governance source repository.

When external Skill discovery, provenance, approval, or supply-chain audit is requested and the active topology maps that intent to Consumer Governance, apply the accepted external-Skill trust boundary without broadening Consumer mutation permissions.
