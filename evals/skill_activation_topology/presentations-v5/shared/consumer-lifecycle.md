# Consumer lifecycle reference

Use only inside an adopting/governed Consumer repository.

Allowed scope: bootstrap/validate installed Agent Governance, inspect or refresh governance state, lifecycle events, sequencing/handoffs, archive readiness, coexistence, and other Consumer-governance operations already defined by the accepted Consumer runtime.

Do not edit the canonical Agent Governance source repository, source checkpoint, source release policy, or source Task Contracts. If the repository role is unclear, ask whether this is an installed Consumer project or the canonical Agent Governance source product before granting Consumer mutation authority.
