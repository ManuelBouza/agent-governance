# External Skill trust reference

Use for Governance-scoped evaluation of third-party/external Agent Skills: discovery, provenance, integrity, supply-chain risk and approval eligibility.

This capability does not grant installation approval by itself, does not use source-maintainer permissions, and does not authorize mutation of the Agent Governance source product. In a Consumer project, preserve installed Governance approval and supply-chain rules. If the request is generic package/Skill installation without Governance trust intent, do not activate this capability.
